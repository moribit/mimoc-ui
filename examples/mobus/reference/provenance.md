# Reference asset provenance

Mo-Bus source: `moribit/Mobus_ESP_IDF`, `fix/after-release`,
`94873ec79bd70d2f38040d173f2f9c89853b5734`.

`glyphs.zig` and `icons.zig` are generated by
`tools/capture_mobus_reference.py`. The converter compiles the original
LovyanGFX rasterizer against the pinned original font arrays, captures each
glyph independently with both `drawString` and `print`, and deduplicates masks.
Opaque background masks are retained separately. Positions/baseline offsets
are encoded in the mask relative to the original text origin. Nothing is
traced from a finished screen or manually redrawn.

`golden/*.raw` is independent C++ output: original Mo-Bus renderer → RGB332
Sprite → original SSD1306 conversion → logical 128×64 page-LSB bytes. The Zig
renderer never generates these files. The manifest records SHA256 of source,
actual LovyanGFX source tree, harness and generated artifacts. Regeneration
uses a staging directory; `--verify` never replaces committed baselines.

The actual installed graphics dependency identifies itself as LovyanGFX
1.2.25. Its complete source hashes, rather than the version string alone,
define this baseline. This does not assert that the installed copy is an
unmodified upstream release. SDL2 is used only to satisfy host platform
functions; no SDL window or physical display is initialized.

## Font notices

- `MobusCustom7`: original `font_mobus_custom7.cpp`, generated by the pinned
  `tools/fonts/gen_mobus_custom_png_font.py`. The source copyright field is
  `(null)`; we preserve that notice in `assets/font-source-notices.txt` and
  do not invent a separate license grant for Mo-Bus-owned artwork.
- `MisakiGothic8`: original `font_misaki_gothic8.cpp`, derived by the pinned
  generator from the author's 2021-05-05 TTF. Mo-Bus includes only
  `$30A0-$30FF`, not the author's complete Japanese font. The original source
  notice is preserved. The author permits copying, modification and
  redistribution, including commercial use, without warranty. See the
  [author's font license](https://littlelimit.net/font.htm#license) and
  [Misaki font provenance](https://littlelimit.net/misaki.htm), checked
  2026-10-10. This port preserves missing-glyph behavior instead of adding
  characters to the frozen reference.
- `Font2`: original LovyanGFX `src/lgfx/Fonts/Font16.h`, rasterized with the
  original `lgfx_fonts.cpp`. Font and graphics dependency notices are retained
  in `assets/LovyanGFX-LICENSE.txt`.

The generic raster policy in `src/renderers/compat.zig` is adapted from
LovyanGFX `LGFXBase.cpp`, with the complete graphics dependency license
available in `assets/LovyanGFX-LICENSE.txt` (including predecessor notices).
Only the reference example links these font tables; Core imports none of them.

## Limits

Converted glyphs cover printable ASCII, the entire current Katakana subset,
fixture characters and the original missing-glyph raster. This is not a new
Japanese system font. No antialiasing, substitute font, typography cleanup or
new Unicode table has been added to Core.

`text/offline` and `text/error` have no golden: original `kOfflineBitmap`
contains 87 bytes while the original call requests 90. The capture tool does
not execute that out-of-bounds read. The safe reference draws the 29 defined
rows and leaves the unknown last row clear; these scenarios are explicitly
SOURCE-FAITHFUL, not VERIFIED.
